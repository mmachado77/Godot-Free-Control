# Godot Free Control (Fork)

This is a customized fork of **[Godot-Free-Control](https://github.com/SoulsTogetherX/Godot-Free-Control)**  
Extended to add **keyboard action support** for the `Carousel` container.

---

## Added Features

- Keyboard enable/disable switch  
- Custom input actions for next / prev / accept  
- Hold-to-repeat navigation (with delay & rate controls)
  
---

## Exported Options (Carousel)

`keyboard_enabled` — master toggle for keyboard control

`action_next` / `action_prev` — input actions for carousel navigation

`action_accept` — confirm / activate action for the current item

`hold_repeat_enabled` — enables continuous navigation while holding keys

`hold_repeat_delay` / `hold_repeat_rate` — tune timing and responsiveness
